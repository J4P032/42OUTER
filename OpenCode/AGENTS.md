# Project: Game of Life (C++)

## Stack
- Lenguaje: C++17
- Compilador: g++

## Build Commands
- Compilar: g++ -std=c++17 main.cpp -o life
- Ejecutar: ./life
- Limpiar: rm -f life

## Reglas de Código
- Todo el código debe estar en `main.cpp`.
- Usar la librería estándar de C++ (`<iostream>`, `<vector>`, `<thread>`, `<chrono>`).
- Mantener las funciones cortas y modulares.
